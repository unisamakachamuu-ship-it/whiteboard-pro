Keep has no public API for personal accounts, so this signs in the way the Android app does. It is a one-off — the token it gets back is remembered on this device.

App Password rejected? Here is the route that still works

Google closed App Passwords for Keep, so a correct one is refused too. The Android sign-in still works and takes about a minute:

  1. Open accounts.google.com/EmbeddedSetup and sign in.
  2. At the screen asking you to accept, press F12 → Application → Cookies → google.com.
  3. Copy the value of the oauth_token cookie — it starts with oauth2_4/.
  4. Paste it above and press Connect. It is single-use and expires within minutes, so do it straight away.

Nothing goes anywhere but Google. The server trades that value for a long-lived token, hands it back, and this browser keeps it so the steps are never repeated.
